# Luno Launcher (репозиторий)

Игроки получают только `run.bat` - он сам скачивает отсюда свежий код при каждом запуске.

## Обновить лаунчер
Измените файлы в репозитории - у игроков обновится при следующем запуске.

## Обновить моды
1. Соберите новый `mods.zip` (папка `mods/` или jar-файлы в корне архива).
2. На GitHub: Releases -> Draft a new release -> новый тег (например `mods-v2`) -> прикрепите `mods.zip`.
3. На своём компьютере:
   `python make_mods_manifest.py mods.zip https://github.com/ВАШ_НИК/ВАШ_РЕПО/releases/download/mods-v2/mods.zip`
4. Загрузите получившийся `mods.json` в корень репозитория (замените старый).

Игроки скачают новые моды при следующем запуске. Если mods.json не обновить, лаунчер продолжит использовать старую сборку.

## Настройки
`config.json`: сервер, версия Minecraft, `mods_manifest_url` (ссылка на raw mods.json).
