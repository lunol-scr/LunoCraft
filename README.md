# LunoCraft launcher - памятка администратора

## Что где лежит
- `core.py`, `ui.py`, `launcher.py` - сам лаунчер. Измените файл - игроки (через `run.bat`) получат его при следующем запуске.
- `config.json` - сервер, версия Minecraft, ссылки на списки модов и статус.
- `mods.json` / `mods_beta.json` - ссылки на сборки модов (создаются автоматически).
- `status.json` - баннер техработ.
- `.github/workflows/` - автоматизация (сборка .exe и mods.json).

## Обновить моды (автоматически)
1. Releases -> Draft a new release.
2. Тег: `mods-v2`, `mods-v3`... (для тестового канала: `mods-beta-1`, `mods-beta-2`...).
3. Прикрепите файл **mods.zip** (имя обязательно именно такое) -> Publish release.
4. Через минуту GitHub сам обновит `mods.json` (или `mods_beta.json`).
Игроки получат новые моды при следующем запуске. Прошлая версия сохраняется - в настройках лаунчера есть кнопка отката.

## Тестовый канал модов
Чтобы получать бета-сборки самому: закройте лаунчер, откройте `%APPDATA%\LunoCraft\launcher_settings.json`
и добавьте строку `"beta": true,` (внутри фигурных скобок). У остальных игроков ничего не меняется.

## Баннер техработ
В `status.json` поставьте `"enabled": true`, напишите `"message"` (до ~70 символов). Если `"block_play": true` - кнопка «Играть» заблокируется.
Через ~5 минут баннер появится у всех, кто открыт или откроет лаунчер. Верните `false`, чтобы убрать.

## Строгий режим модов
`"strict_mods": true` в `config.json` - лаунчер будет переносить чужие моды из папки mods в mods_removed.
Изменённые или удалённые моды из сборки лаунчер восстанавливает всегда.
Это не защита от читеров (они могут обойти лаунчер), а защита от случайных нарушений.

## .exe без Python
При каждом изменении кода GitHub сам собирает `LunoLauncher.exe` (вкладка Actions) и кладёт в релиз `launcher`:
`https://github.com/lunol-scr/LunoCraft/releases/download/launcher/LunoLauncher.zip`.
Игроки распаковывают zip в любую папку (лучше не в Program Files) и запускают LunoLauncher.exe. Дальше он обновляется сам.
